# Sleep Health and Lifestyle Analysis

## Project Overview
This project analyses sleep health and lifestyle patterns using Python. It explores relationships between sleep duration, sleep quality, stress levels, physical activity, and sleep disorders.

## Objectives
- Inspect and understand the dataset.
- Clean missing values and prepare the data.
- Perform Exploratory Data Analysis (EDA).
- Identify important patterns and findings.
- Create visualisations to communicate the results.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Visual Studio Code

## Dataset Information
- Total records: 374
- Total columns: 13
- Original missing values: 219 in the Sleep Disorder column.
- Duplicate records: 0

## Project Files
- `01_data_inspection.py` – Dataset inspection and cleaning.
- `02_exploratory_data_analysis.py` – Exploratory data analysis.
- `03_data_visualization.py` – Data visualisation.
- `Sleep_Health_Analysis_Report.pdf` – Final project report.
- `sleep_health_cleaned.csv` – Cleaned dataset.
- `sleep_health_dashboard.png` – Visualisation dashboard.

## Key Findings
- Average sleep duration: approximately 7.13 hours.
- Average sleep quality score: approximately 7.31.
- Average stress level: approximately 5.39.
- Sleep Apnea records: 78.
- Insomnia records: 77.
- Average sleep duration for females: approximately 7.23 hours.
- Average sleep duration for males: approximately 7.04 hours.

## Conclusion

This project demonstrates how Python can be used to inspect, clean, analyse, and visualise real-world health and lifestyle data.
